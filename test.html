🔄 Tab Cycling Gestures Test

Open multiple tabs in your browser, then try these gestures directly on this page:

  • Alt + Two-Finger Scroll (Both Left & Right Alt Supported): Hold down either Left Alt or Right Alt (AltGr) and scroll two fingers up/down or swipe left/right on your mousepad to smoothly cycle tabs without lag, runaway skips, or Windows menu focus!
  • Right-Click + Wheel Scroll Down: Switches to the next tab (▶).
  • Right-Click + Wheel Scroll Up: Switches to the previous tab (◀).
  • Mouse Swipe Mode: Swipe Right = Next Tab (▶), Swipe Left = Previous Tab (◀).
  • Mousepad / Trackpad Mode: Swipe Left = Next Tab (▶), Swipe Right = Previous Tab (◀).
  • Rocker Gestures (Mousepad): Hold Left-Click + Click Right-Click (Next Tab ▶). Hold Right-Click + Click Left-Click (Prev Tab ◀).
  • Double Right-Click: Double click right mouse button quickly anywhere on the page to close the active tab!

Tip: Toggle gestures and customize device modes in the extension popup!

🔍 Selected Text Gestures (Search, Copy & Cut)

Select any portion of the sample text below or in the input box, then test the gestures:

"HoldTab empowers ultra-fast tab navigation with mouse gestures, text search hold, and instant copy/cut."
  • 🌐 Alt + Hold Left Mouse Button on Text: Select text, hold Alt + Left-Hold for ~450ms → animates a Cyan ring ("Search Site"), fills the current site's search bar, and automatically executes the search in the current tab!
  • ↗️ Alt + Hold Right Mouse Button on Text: Select text, hold Alt + Right-Hold for ~450ms → animates a Teal ring ("Search Site (New Tab)") and opens a new tab with the current website searching your text!
  • 🔍 Alt + Double Left-Click: Select text, hold Alt + double left-click → fills the current site's search bar and focuses it without auto-submitting.
  • 📋 Double Left-Click on Selected Text: Copies already-selected text to your clipboard. Triple-clicking smoothly selects all text/paragraphs without accidentally triggering copy!
  • 📋 Double Left-Click to Paste in Input: Double left-click between words (e.g. between "hello" and "world"), at the start/end, or in empty input to paste clipboard text with automatic smart word spacing! Inside a word, it preserves native double-click word selection.
  • ✂️ Double Right-Click on Selected Text: Cuts already-selected text (copies to clipboard and deletes it from inputs/textareas) with an on-screen HUD confirmation!
  • 🖱️ Drag & Drop Selected Text: Double-click or highlight any text and drag it anywhere (like into the empty input box above) — native browser drag-and-drop works seamlessly!
  • 🟡 Hold Left Mouse Button on Text: Select text, then hold left mouse button for ~450ms $\rightarrow$ opens background Google search tab (Amber ring with magnifying glass icon).
  • 🟣 Hold Right Mouse Button on Text: Select text, then hold right mouse button for ~450ms $\rightarrow$ opens active Google search tab (Purple ring with magnifying glass icon).
