📋 A. Instant Clipboard Operations (No Keyboard Needed)
📋 Copy Selected Text Instant Copy
👉 HOW TO DO IT: Highlight text ➔ Double Left-Click on it • Shows green "📋 Copied" badge! (Triple-click selects full paragraphs).
✂️ Cut Selected Text Instant Cut
👉 HOW TO DO IT: Highlight text in an input ➔ Double Right-Click on it • Copies to clipboard and removes it with a "✂️ Cut" HUD badge!
📋 Smart Paste with Word Spacing Smart Paste
👉 HOW TO DO IT: Double Left-Click in empty input or between words • Automatically handles spacing (e.g. "hello [paste] world" -> "hello pasted-text world").
🌐 B. Search the Current Website
🌐 Search Current Site (In This Tab) Cyan Ring
👉 HOW TO DO IT: Highlight text ➔ Hold Alt + Left-Click (~450ms) • Animated Cyan Ring fills ➔ Automatically finds site's search bar & searches here!
↗️ Search Current Site (In a New Tab) Teal Ring
👉 HOW TO DO IT: Highlight text ➔ Hold Alt + Right-Click (~450ms) • Animated Teal Ring fills ➔ Opens a new tab with current site searching your query!
🔍 Fill Search Bar & Focus Cursor Fill Only

🔄 3. Tab Cycling & Quick Tab Actions

Multi-Tab Gestures

Open several tabs in your browser to experience seamless tab switching:

💻 Smooth Trackpad Two-Finger Tab Cycling Mousepad Native
👉 HOW TO DO IT: Hold Left Alt or Right Alt + Scroll Two Fingers Up/Down • Calibrated friction-free tab switching without Windows Alt-menu flashes!
🖱️ Mouse Wheel Tab Switch (Next / Prev Tab) Mouse Scroll
👉 HOW TO DO IT: Hold Right-Click + scroll Wheel Down (Next ▶) or Wheel Up (Prev ◀)
⚡ Rocker Gestures (Binary Switch) Fast Switching
👉 HOW TO DO IT: Hold Left-Click + click Right (Next ▶) • Hold Right-Click + click Left (Prev ◀)
❌ Instant Close Tab Close Gesture
👉 HOW TO DO IT: Double Right-Click quickly anywhere on empty space • Closes the active tab with clean context menu suppression!
