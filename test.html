🔄 Tab Cycling Gestures Test

Open multiple tabs in your browser, then try these gestures directly on this page:

  • Alt + Two-Finger Scroll (Both Left & Right Alt Supported): Hold down either Left Alt or Right Alt (AltGr) and scroll two fingers up/down or swipe left/right on your mousepad to smoothly cycle tabs without lag, runaway skips, or Windows menu focus!
  • Right-Click + Wheel Scroll Down: Switches to the next tab (▶).
  • Right-Click + Wheel Scroll Up: Switches to the previous tab (◀).
  • Mouse Swipe Mode: Swipe Right = Next Tab (▶), Swipe Left = Previous Tab (◀).
  • Mousepad / Trackpad Mode: Swipe Left = Next Tab (▶), Swipe Right = Previous Tab (◀).
  • Rocker Gestures (Mousepad): Hold Left-Click + Click Right-Click (Next Tab ▶). Hold Right-Click + Click Left-Click (Prev Tab ◀).
  • Double Right-Click: Double click right mouse button quickly anywhere on the page to close the active tab!

Tip: Toggle gestures and customize device modes in the extension popup!

🔍 Selected Text Gestures (Search, Copy & Cut)

Select any portion of the sample text below or in the input box, then test the gestures:

"HoldTab empowers ultra-fast tab navigation with mouse gestures, text search hold, and instant copy/cut."
  • 📋 Double Left-Click on Selected Text: Copies the selected text to your clipboard with an on-screen HUD confirmation!
  • 📋 Double Left-Click in Input Field: Place cursor in any input box or textarea (with no text selected) and double left-click to paste clipboard text!
  • ✂️ Double Right-Click on Selected Text: Cuts the selected text (copies to clipboard and deletes it from inputs/textareas) with an on-screen HUD confirmation!
  • Hold Left Mouse Button: Select text, then hold left mouse button for ~450ms $\rightarrow$ opens new foreground tab searching Google.
  • Hold Right Mouse Button: Select text, then hold right mouse button for ~450ms $\rightarrow$ opens new background tab searching Google (red circle UI).
